Lahore Route Planner

Smart Navigation System · Dijkstra's shortest path

Tip: click a junction on the map to set the start, then another to set the destination.

Plan your own route stop by stop. Each stop is pushed onto a stack; Undo stop pops the last one.

Change conditions and the next route search adapts. Heavy traffic counts as 1.5× the distance; blocked or closed roads are skipped.
